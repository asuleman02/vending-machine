This file contains a C++ program that simulates a simple vending machine. The program displays a menu of items, including their prices and available stock. The user can select an item by entering a number or exit the program by choosing zero.

The program checks user input to make sure only valid numbers are entered, which helps prevent errors and crashes. It also checks whether the selected item is in stock before allowing a purchase. If the item is available, the program asks the user to insert money and verifies that the amount is sufficient. If not enough money is entered, the amount is refunded.

When a purchase is successful, the program dispenses the item, calculates and returns the correct change, and updates the stock level. The program continues running until the user chooses to exit.
